# 24 — v1.8.2 DeepSeek 1M 上下文与峰谷价格刷新：DCP-1 至 DCP-4 实施指导书

状态：RELEASE CANDIDATE（仓库候选门禁已通过、尚未发布；公开 Latest 仍为 `v1.8.1`）。
制定日期：2026-08-29
目标：让 Claude Code 对两个 DeepSeek Profile 中的所有实际模型都按 1M 窗口管理上下文，并把 `deepseek-v4` Pricing 从 2026-07-23 的单档旧价格刷新为当前官方三模型、工作日峰谷 USD 价格。

## 1. 根因与官方事实

DeepSeek 当前模型与价格页把 `deepseek-v4-pro`、`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 同列为 1M 上下文、最大输出 384K，三者均支持 Anthropic API。Flash Vision 与 Flash 同价：

- https://api-docs.deepseek.com/quick_start/pricing/
- https://api-docs.deepseek.com/zh-cn/quick_start/pricing/

DeepSeek 当前 Claude Code 接入页仍只给 Pro 模型加 `[1m]`，Flash 使用裸模型 ID：

- https://api-docs.deepseek.com/zh-cn/guides/coding_agents/

Claude Code 当前模型配置文档明确：对于网关或自定义模型 ID，`CLAUDE_CODE_MAX_CONTEXT_TOKENS` 用来声明 Claude Code 应假定的实际窗口；对不以 `claude-` 开头、不含 `[1m]` 且无法解析为 Claude 模型的 ID，该变量直接生效并保留主动压缩。对于带 `[1m]` 的未知 ID，Claude Code 已直接假定 1M，变量不单独覆盖：

- https://code.claude.com/docs/en/model-config#correct-the-window-for-a-gateway-or-custom-model-id

因此当前 CMR 的差异不是 DeepSeek 模型真实能力差异，而是 Claude Code 选择层声明不完整：Pro 槽已用 `[1m]`，Vision 裸 ID 槽未向 Claude Code 声明窗口。`config/pricing/deepseek-v4.json` 虽已记录 `1048576`，但 Pricing 不参与子进程环境，不能修正 Claude Code 的上下文预算。

## 2. 绑定行为合同

### 2.1 两个 DeepSeek Profile

`deepseek` 与 `deepseek-vision` 都新增：

```text
CLAUDE_CODE_MAX_CONTEXT_TOKENS=1048576
```

- `deepseek` 的主模型/Opus/Sonnet 继续使用 `deepseek-v4-pro[1m]`；Haiku/子 Agent 继续使用裸 ID `deepseek-v4-flash-vision-exp`。
- `deepseek-vision` 的全部模型槽继续使用裸 ID `deepseek-v4-flash-vision-exp`。
- 不给 Vision ID 追加尚未被 DeepSeek Claude Code 示例直接采用的 `[1m]`，不增加 Fable、auto-compact、timeout、Tool Search 或代理逻辑。
- 一个全局 max-context 声明对混合 Profile 是安全的：Pro 的 `[1m]` 已独立选择 1M；裸 Vision ID 由该变量声明 1M。DeepSeek 当前三个可用模型均为 1M。

### 2.2 DeepSeek Pricing

`config/pricing/deepseek-v4.json` 保持：

```text
currency=USD
unit=per_million_tokens
contextWindowTokens=1048576
```

`prices` 改为三模型、两时段结构；每个模型节点恰好包含 `offPeak` 与 `peak`，每个时段恰好包含 `inputCacheHit`、`inputCacheMiss`、`output`：

| Model | Period | Cache hit | Cache miss | Output |
|---|---|---:|---:|---:|
| `deepseek-v4-flash` | offPeak | 0.007 | 0.22 | 0.66 |
| `deepseek-v4-flash` | peak | 0.014 | 0.44 | 1.32 |
| `deepseek-v4-pro` | offPeak | 0.022 | 0.66 | 1.98 |
| `deepseek-v4-pro` | peak | 0.044 | 1.32 | 3.96 |
| `deepseek-v4-flash-vision-exp` | offPeak | 0.007 | 0.22 | 0.66 |
| `deepseek-v4-flash-vision-exp` | peak | 0.014 | 0.44 | 1.32 |

官方定义峰值时段为 UTC 周一至周五 01:00–04:00、06:00–10:00；其余为非峰值。CMR 只保存价格意识数据，不根据本机时间选择费率、不计算会话费用、不查询余额。

### 2.3 不变量

- Provider、Profile、别名、Secret、Base URL、鉴权变量与模型槽分工不变。
- 只使用假 Key 与假 Claude 验证；不发起真实 Provider 请求。
- 不修改用户 Settings、Shell、Secret Store、全局安装、CI 或远端。
- 版本号可在仓库候选中收口到 `1.8.2`；commit、push、Windows CI、tag 与 Release 仍需项目负责人后续逐项授权。
