# 12 — `1.2.1` Windows 兼容性补丁与发布证据

状态：PASS — READY FOR RELEASE
日期：2026-07-24

## 1. 结论与范围

`1.2.1` 是对误打但已公开的 `v1.2.0` 代码标签的完整修复性发布。现有 `v1.2.0` 不删除、不移动、不重写；`v1.2.1` 补齐版本、README、规格、针对性测试和发布证据。

本补丁只声明以下问题已修复：

- Windows 环境副本使用 `Path` 或其他大小写时，CMR 仍能发现 Claude Code。
- PATH 未包含 Claude 时，CMR 后备检查官方原生安装目录 `%USERPROFILE%\.local\bin\claude.exe`。
- Windows Doctor 不再输出 POSIX Settings 权限误报警告。
- Windows 路径分隔符和连接规则可在非 Windows 主机可靠模拟。

完整 Windows 实机阶段仍按 `docs/05-phase-3-windows.md` 执行。

## 2. 根因

`buildChildEnvironment()` 会把 `process.env` 展开为普通对象。Windows 环境变量名不区分大小写，但普通 JavaScript 对象区分；实际键名可能是 `Path`，而旧的 `findClaudeExecutable()` 只读取 `env.PATH`。

公司 Windows 修复提交 `7394041` 同时增加了官方原生目录后备查找，并在 Doctor 中排除了 Windows POSIX mode 警告，但没有同步 package/CLI/README，也没有增加针对性测试。随后创建的 `v1.2.0` tag 因此存在版本元数据不一致，且没有 GitHub Release。

## 3. 实现

- `src/platform.js`
  - Windows 下按不区分大小写查找 PATH 键。
  - 使用 `path.win32.delimiter/join`。
  - PATH 候选之后检查 `%USERPROFILE%\.local\bin`。
- `src/commands/doctor.js`
  - 保留现有 Windows POSIX 权限警告抑制。
- `tests/platform.test.js`
  - 覆盖 PATH 任意大小写、官方后备目录、显式 pathValue 优先级。
- `tests/doctor.test.js`
  - 覆盖 Windows Settings 不输出 POSIX 权限警告。

## 4. 不变合同

- 仍只有 `kimi` 与 `deepseek` 两个数据化 Profile。
- Provider Base URL、模型映射、价格与官方核验事实不变。
- Secret Store、Setup State、隐藏输入与首次向导不变。
- Claude argv、cwd、TTY、信号和退出码合同不变。
- 不修改用户 Settings、Shell、系统环境、真实 Key、Codex 或 CI/CD。
- 不新增运行时依赖或安装生命周期脚本。
