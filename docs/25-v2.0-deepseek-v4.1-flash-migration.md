# 25 — v2.0.0 DeepSeek V4.1 Flash 迁移：DS41-1 至 DS41-5 实施指导书

状态：**RELEASED PASS — `v2.0.0` 已发布为 immutable Latest，公开安装与完整更新回读闭环**

制定日期：2026-09-10

目标：以唯一的 `deepseek` Profile 接入 DeepSeek V4.1 Flash（官方模型 ID `deepseek-flash`），替代 V4 Pro、V4 Flash 与 V4 Flash Vision 三套旧映射；删除旧的 DeepSeek Vision Profile 和品牌别名，以 `2.0.0` 明确承载破坏性迁移。

## 1. 结论与版本决策

本轮是破坏性主版本升级，不采用“旧命令静默转发到新模型”的兼容策略：

- 唯一 DeepSeek 规范入口为 `cmr deepseek`。
- 历史通用工作流别名 `cmr build` 保留并继续解析到 `deepseek`。
- 删除 `deepseek-auto`、`deepseek-vision`、`deepseek-flash-vision` 三个旧品牌入口。
- 删除旧 `deepseek-vision` Profile；不增加 Provider、Secret 或凭据边界。
- 所有 Claude Code 模型槽位改由 `deepseek-flash` 承担。

上述入口清理是 CMR 产品决策，不是 DeepSeek 官方迁移要求。项目负责人于 2026-09-10 明确选择直接进入 `2.0.0`，并授权移除旧 DeepSeek Profile/别名；发布前公开稳定版保持 `1.8.2`，完成全部门禁后 `v2.0.0` 已成为 immutable Latest。

## 2. 官方事实（2026-09-10 复核）

### 2.1 DeepSeek 模型与 Claude Code 配置

DeepSeek 官方更新日志与当前 Claude Code 指南确认：

- DeepSeek V4.1 Flash 已发布，官方 API 模型 ID 是 `deepseek-flash`，原生支持多模态。
- 官方声明其综合能力超过 V4 Pro；旧 `deepseek-v4-flash` 与 `deepseek-v4-flash-vision-exp` 已下线并暂时路由至新模型。

- Claude Code 官方示例将主模型、Opus、Sonnet 设为 `deepseek-flash[1m]`，Haiku 与子 Agent 设为 `deepseek-flash`，effort 设为 `max`，主动压缩窗口设为 `786432`。

### 2.2 `[1m]` 与 `[text]` / `[image]` 不是同一类机制

Claude Code 模型配置文档目前只定义 `[1m]` 这一模型后缀：它用于选择 1M 上下文，并在发送请求前从模型 ID 中移除。官方没有把 `[text]`、`[image]` 定义为能力标签或模型选择语法。

Claude Code 的 `Read` 工具会把文本作为带行号的文本内容返回，把图片作为模型可见的视觉内容返回。是否能理解图片，由当前上游模型和 Anthropic 兼容端点是否接受 `image` 内容块决定；DeepSeek 官方 Anthropic API 与图像指南明确 `deepseek-flash` 支持该内容块。因此，多模态链路是：

```text
Read(image) -> Claude Code 视觉内容块 -> DeepSeek Anthropic API image block -> deepseek-flash
```

而不是：

```text
ANTHROPIC_MODEL=deepseek-flash[image]
```

本地无密钥请求捕获（Claude Code `2.1.266`，2026-09-10）进一步确认：`deepseek-flash[1m]` 发往上游时会变成 `deepseek-flash`；`deepseek-flash[image]` 会触发 Claude Code 的 `unrecognized_model` 提示，并以带后缀的原始字符串发往上游。即使 DeepSeek 当前会把不支持的模型名自动映射到 `deepseek-flash`，也只是 Provider fallback，不能作为能力声明合同。

来源：

- https://code.claude.com/docs/en/model-config
- https://code.claude.com/docs/en/tools-reference
- https://code.claude.com/docs/en/common-workflows
- https://api-docs.deepseek.com/zh-cn/guides/anthropic_api/

## 3. 绑定行为合同

### 3.1 Profile 与环境变量

`config/profiles/deepseek.json` 必须精确使用：

```text
ANTHROPIC_MODEL=deepseek-flash[1m]
ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-flash[1m]
ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-flash[1m]
ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-flash
CLAUDE_CODE_SUBAGENT_MODEL=deepseek-flash
CLAUDE_CODE_EFFORT_LEVEL=max
CLAUDE_CODE_AUTO_COMPACT_WINDOW=786432
CLAUDE_CODE_MAX_CONTEXT_TOKENS=1048576
```

前七项与 DeepSeek 当前 Claude Code 指南一致。`CLAUDE_CODE_MAX_CONTEXT_TOKENS=1048576` 是 CMR 延续 `docs/24` 的客户端上下文补充：Claude Code 官方文档允许网关/自定义裸模型 ID 用该变量声明真实窗口，因此 Haiku 与子 Agent 的裸 `deepseek-flash` 也按官方 1M 窗口管理；它不是 DeepSeek 示例中的必填项。

不得加入 `[text]`、`[image]`、Fable、timeout、代理或内容路由变量。

### 3.2 Provider 与 Secret 不变量

- Provider ID、Secret Store 槽与 `ANTHROPIC_AUTH_TOKEN` 均继续使用 `deepseek`。
- Base URL 继续为 `https://api.deepseek.com/anthropic`。
- 旧版已保存的 DeepSeek Key 无需迁移或重新录入。
- CMR 不检测输入模态，不根据文字/图片动态改写模型名。

### 3.3 Pricing

旧 `deepseek-v4` 价格记录由 `deepseek-flash` 单模型记录替代：

| Period | Cache hit | Cache miss | Output |
|---|---:|---:|---:|
| offPeak | 0.003 USD/M | 0.15 USD/M | 0.60 USD/M |
| peak | 0.006 USD/M | 0.30 USD/M | 1.20 USD/M |

官方峰值时段为 UTC 工作日 01:00–04:00 与 06:00–10:00。CMR 只保存价格事实，不按时间自动选价、不计算账单。

来源：https://api-docs.deepseek.com/quick_start/pricing/
